# How-to-fit-a-snake-in-a-box-gng

How-to-fit-a-snake-in-a-box-gng is a compact Snake game written as a single HTML/JavaScript data:text/html, URI and optimized to fit inside a strict 3,072-byte limit.

## Gameplay

The game uses a 20×20 grid with a dark neon visual style. You start with 3 lives and gain points by eating food. Every 5 normal foods increases the level and the game becomes faster as the level rises.

Colliding with a wall, your own body, or the boss costs a life. After being hit the snake gets a short period of invulnerability.

## Power-ups

Golden food: +50 points.

SLOW: temporarily reduces the game speed.

GHOST: temporarily lets the snake pass through collisions and obstacles.

Special power-ups appear randomly after normal food is eaten.

## Boss

A boss appears every 5th level with 3 HP. When a boss starts, the wall arena is cleared.

Eat the cyan orbs to damage it. Each orb removes 1 HP. Defeating the boss awards extra points and +1 life, up to a maximum of 5 lives.

## Codes & Easter Eggs

HACK: Press Shift + \, then Enter to gain +30 points.

KONAMI: ↑ ↑ ↓ ↓ ← → ← → B A activates Rainbow Mode and gives +1 life.

42: Reaching a score of 42 triggers a small Easter egg message.

## Controls

PC: Arrow keys or WASD.

Mobile: Swipe in the direction you want to move.

Space: Pause / resume.

Enter or tap after Game Over: Restart.

## Technical Notes

size: 3,070 / 3,072 bytes.

## Project Description

I started this project without really knowing JavaScript—only a very small amount of cybersecurity knowledge. I ended up combining that tiny bit of knowledge with the skills I already had in code compression and optimization. The main challenge was fitting a complete playable game, with power-ups, a boss fight, Easter eggs, keyboard and mobile controls, visual effects, levels, lives, and score tracking, into only 3,072 bytes.

It was a reeeeaaaallllyyy fun exercise in making every byte count while still keeping the game playable and recognizable as a full Snake game.
